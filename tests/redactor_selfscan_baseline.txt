# Lines in the shipped tree that chamnan's own redactor would alter, and why each is accepted.
#
# Written 2026-09-09, the first time the redactor was pointed at the tree it ships in. It knows
# seventy-one credential shapes and had only ever been tested against fixtures. Every line here was
# read before it was added; none is a real credential.
#
# Two kinds, and the second is a defect this file exists to keep visible rather than hide:
#
#   Documented examples — AWS's own published AKIAIOSFODNN7EXAMPLE, a test card number, an xkcd
#   password. Quoting these is what the documentation is for.
#
#   The redactor's own false positives — `"input_tokens": u.get("input_tokens", 0)` is destroyed
#   because the word `token` sits beside a value, and so are `index_token_budget`, `ENV_FILE_KEY`
#   and `_AUTHORED_SFC_EXTS`. Any user whose code contains `input_tokens` has that line mangled in
#   their index. That is a real bug with a real cost, recorded here until it is fixed.
#
# One sha256 prefix of the stripped line, and the file it is in. A line that changes leaves the
# baseline and the gate fails, which is the point: the accepted set may only shrink by hand.
#
