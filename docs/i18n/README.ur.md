## یہ کیا ہے

Claude Code کا ایک پلگ اِن۔ یہ ریپوزٹری کی ایک فہرست بناتا ہے جسے ایجنٹ فائلیں ایک ایک کر کے کھنگالنے کے بجائے پڑھتا ہے، اور کام کے دوران جمع ہونے والا تکنیکی سیاق محفوظ رکھتا ہے — کام کی حالت، سیشن کے ریکارڈ، فیصلوں کے پیچھے کی وجوہات، اور وہ طریقے جو آپ ہر بار نئے سرے سے نکالتے ہیں۔

یہ جو کچھ لکھتا ہے وہ سادہ markdown ہے جو کوڈ کے ساتھ ہی commit ہوتا ہے۔ چلتے وقت کوئی نیٹ ورک کال نہیں، کوئی ڈیٹابیس نہیں، کوئی daemon نہیں، کوئی embedding ماڈل نہیں — صرف Python کی معیاری لائبریری۔

## یہ کیا حل کرتا ہے

ہر نئے سیشن میں، یا جب بھی سیاق دبایا جاتا ہے، ایجنٹ نے آپ کے کوڈ کے بارے میں جو سمجھا تھا وہ مٹ جاتا ہے اور وہ دوبارہ شروع سے تلاش کرنے لگتا ہے۔

chamnan اس دوبارہ دریافت کو ہونے ہی نہیں دیتا: فہرست سیشن کے آغاز پر ہی دے دی جاتی ہے، اور قیمت ایک معلوم، محدود عدد ہوتی ہے، نہ کہ لامحدود فائل خوانی۔

## یہ کیا لکھتا ہے، اور کہاں

سب کچھ `.chamnan/` کے اندر، سادہ markdown اور JSON۔ پڑھا جا سکتا ہے، ہاتھ سے بدلا جا سکتا ہے، کسی بھی وقت مٹایا جا سکتا ہے — کچھ نہیں ٹوٹے گا۔

| | |
|---|---|
| `MAP.md` | کیا موجود ہے، اور کیا کس پر منحصر ہے |
| `STATE.md` | اس وقت کیا کیا جا رہا ہے |
| `sessions/` | پچھلا کام کہاں رکا |
| `memory/` | فیصلے، اسباق اور مستقل اصول |
| `threads/` | ابھی کھلی کام کی لڑیاں |
| `skills/` · `tools/` | رکھنے کے قابل طریقے اور اسکرپٹ |
| `milestones.md` | وہ تبدیلیاں جنہوں نے ریپازٹری کی شکل بدلی |
| `config.json` | ہر حصے کا چالو بند، اور سیشن میں شامل ہونے والے حصے کی حجمی حد |

**`.chamnan/` سے باہر واحد تحریر** ایک اختیاری Git pre-commit hook ہے، جو اشاریے کو کوڈ کے ساتھ چلاتا رکھتا ہے — یہ صرف تب لگتا ہے جب آپ ہاں کہیں، اور ہٹایا جا سکتا ہے۔

**ایجنٹ کچھ نہیں سیکھتا۔** کچھ تربیت نہیں پاتا، اس ڈائریکٹری سے باہر کچھ نہیں رہتا، اور اگلا سیشن پھر صفر سے شروع ہوتا ہے — بس صفر سے *ایسی ریپازٹری میں* جو خود کو سمجھا سکے۔ تسلسل تحریروں میں ہے، ماڈل میں نہیں۔

## یہ کن کے ساتھ کام کرتا ہے

chamnan محض متن اور معیاری لائبریری کا پائتھون ہے۔ فہرست میں کوئی چیز کسی ایک فراہم کنندہ، کسی ایک ایڈیٹر یا کسی ایک آپریٹنگ سسٹم کی نہیں۔

| | |
