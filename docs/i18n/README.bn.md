## এটি কী

Claude Code-এর একটি প্লাগিন। এটি রিপোজিটরির একটি সূচি তৈরি করে যা agent ফাইল একে একে ঘাঁটার বদলে পড়ে, এবং কাজ করতে করতে জমে ওঠা কারিগরি প্রেক্ষাপট ধরে রাখে — কাজের অবস্থা, সেশনের নথি, সিদ্ধান্তের পেছনের কারণ, আর যে ধাপগুলো আপনি প্রতিবার নতুন করে বের করেন।

এটি যা কিছু লেখে সবই সাধারণ markdown, কোডের পাশেই commit করা। চলার সময় কোনো নেটওয়ার্ক কল নেই, ডেটাবেস নেই, daemon নেই, embedding মডেল নেই — কেবল Python-এর স্ট্যান্ডার্ড লাইব্রেরি।

## এটি কী সমাধান করে

প্রতিটি নতুন সেশনে, বা যতবার প্রেক্ষাপট সংকুচিত হয়, agent আপনার কোডবেস সম্পর্কে যা বুঝেছিল তা মুছে যায় এবং সে আবার গোড়া থেকে খুঁজতে শুরু করে।

chamnan সেই পুনরাবিষ্কারটিকে ঘটতেই দেয় না: সূচি সেশনের শুরুতেই হাতে তুলে দেওয়া হয়, আর খরচ একটি জানা, সীমাবদ্ধ সংখ্যা — অসীম ফাইল-পাঠ নয়।

## সমস্ত বৈশিষ্ট্য

## এটি কী লেখে, আর কোথায়

সবই `.chamnan/`-এর ভিতরে, সাধারণ markdown ও JSON। পড়া যায়, হাতে সম্পাদনা করা যায়, যেকোনো সময় মুছে ফেলা যায় — কিছুই ভাঙে না।

| | |
|---|---|
| `MAP.md` | কী আছে, আর কী কীসের উপর নির্ভরশীল |
| `STATE.md` | এই মুহূর্তে কী করা হচ্ছে |
| `sessions/` | আগের কাজ কোথায় থেমেছিল |
| `memory/` | সিদ্ধান্ত, শিক্ষা ও স্থায়ী নিয়ম |
| `threads/` | এখনও খোলা কাজের ধারা |
| `skills/` · `tools/` | রাখার মতো কার্যপদ্ধতি ও স্ক্রিপ্ট |
| `milestones.md` | যেসব পরিবর্তন রিপোজিটরির আকার বদলেছে |
| `config.json` | প্রতিটি অংশের চালু-বন্ধ, আর সেশনে ঢোকানো খণ্ডটির আকার-সীমা |

**`.chamnan/`-এর বাইরে একমাত্র লেখা** হলো একটি ঐচ্ছিক Git pre-commit hook, যা সূচিকে কোডের সঙ্গে তাল মিলিয়ে রাখে — আপনি সম্মতি দিলে তবেই বসে, আর খুলে ফেলা যায়।

**এজেন্ট কিছু শেখে না।** কিছুই প্রশিক্ষিত হয় না, এই ডিরেক্টরির বাইরে কিছু থাকে না, আর পরের সেশনও শূন্য থেকেই শুরু হয় — কেবল শূন্য থেকে শুরু হয় *এমন এক রিপোজিটরিতে যা নিজেকে ব্যাখ্যা করতে পারে*। ধারাবাহিকতা ফাইলে, মডেলে নয়।
