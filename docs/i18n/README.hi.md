## यह क्या है

Claude Code का एक प्लगिन। यह रिपॉज़िटरी की एक सूची बनाता है जिसे agent फ़ाइलें एक-एक करके खंगालने के बजाय पढ़ता है, और काम के दौरान जमा हुआ तकनीकी संदर्भ सहेजता है — काम की स्थिति, सत्र के अभिलेख, निर्णयों के पीछे के कारण, और वे प्रक्रियाएँ जो आप हर बार दोबारा निकालते हैं।

यह जो कुछ लिखता है वह सादा markdown है, कोड के साथ ही commit किया हुआ। चलते समय कोई नेटवर्क कॉल नहीं, कोई डेटाबेस नहीं, कोई daemon नहीं, कोई embedding मॉडल नहीं — केवल Python की मानक लाइब्रेरी।

## यह क्या हल करता है

हर नए सत्र में, या जब भी संदर्भ संपीड़ित होता है, agent ने आपके कोडबेस के बारे में जो समझा था वह मिट जाता है और वह फिर से खोजना शुरू कर देता है।

chamnan उस दोबारा खोज को होने ही नहीं देता: सूची सत्र के आरंभ में ही सौंप दी जाती है, और लागत एक ज्ञात, सीमित संख्या होती है — असीमित फ़ाइल-पठन नहीं।

## सभी विशेषताएँ

चार क्षमताएँ। नीचे सूचीबद्ध सब कुछ मौजूदा रिलीज़ में सचमुच चल रहा है। हर हिस्सा `.chamnan/config.json` में अलग से बंद किया जा सकता है, और कोई हिस्सा दूसरे पर निर्भर नहीं है।

## यह क्या लिखता है, और कहाँ

सब कुछ `.chamnan/` के भीतर, सादा markdown और JSON। पढ़ा जा सकता है, हाथ से बदला जा सकता है, और कभी भी मिटाया जा सकता है — कुछ नहीं टूटेगा।

| | |
|---|---|
| `MAP.md` | क्या मौजूद है, और क्या किस पर निर्भर है |
| `STATE.md` | इस समय क्या किया जा रहा है |
| `sessions/` | पिछला काम कहाँ रुका |
| `memory/` | निर्णय, सबक़ और स्थायी नियम |
| `threads/` | अब भी खुली कार्य-धाराएँ |
| `skills/` · `tools/` | रखने लायक़ कार्यविधियाँ और स्क्रिप्ट |
| `milestones.md` | वे बदलाव जिन्होंने रिपॉज़िटरी का आकार बदला |
| `config.json` | हर हिस्से का चालू-बंद, और सत्र में डाले जाने वाले खंड की आकार-सीमा |

**`.chamnan/` के बाहर एकमात्र लेखन** एक वैकल्पिक Git pre-commit hook है, जो सूचकांक को कोड के साथ बनाए रखता है — यह तभी लगता है जब आप हाँ कहें, और हटाया जा सकता है।

**एजेंट कुछ सीखता नहीं।** कुछ भी प्रशिक्षित नहीं होता, इस निर्देशिका के बाहर कुछ नहीं बचता, और अगला सत्र फिर शून्य से ही शुरू होता है — बस शून्य से *ऐसी रिपॉज़िटरी में* जो ख़ुद को समझा सके। निरंतरता कृतियों में है, मॉडल में नहीं।

## यह किसके साथ काम करता है

chamnan केवल टेक्स्ट और मानक लाइब्रेरी वाला पायथन है। सूची में ऐसा कुछ नहीं जो किसी एक विक्रेता, किसी एक एडिटर या किसी एक ऑपरेटिंग सिस्टम का हो।

## स्थापित करने से पहले पढ़ें
