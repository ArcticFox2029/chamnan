## Що це

Плагін для Claude Code. Він будує індекс репозиторію, який агент читає замість того, щоб переглядати файли по одному, і зберігає інженерний контекст, накопичений під час роботи, — стан роботи, записи сесій, причини рішень і процедури, які ви щоразу виводите наново.

Усе, що він пише, — звичайний markdown, закомічений поруч із кодом. Жодних мережевих викликів під час роботи, жодної бази даних, жодного демона, жодної embedding-моделі — лише стандартна бібліотека Python.

## Що він розв'язує

З кожною новою сесією — і щоразу, коли контекст стискається, — усе, що агент зрозумів про вашу кодову базу, зникає, і він знову починає шукати з нуля.

chamnan робить це повторне відкриття непотрібним: індекс передається на початку сесії, а ціна — відоме й обмежене число, а не безмежне читання файлів.

## Встановлення

```bash
claude plugin marketplace add ArcticFox2029/chamnan
claude plugin install chamnan@chamnan
```

Відкрийте нову сесію та виконайте `/chamnan:bootstrap` один раз для кожного репозиторію.

## Прочитайте перед встановленням

**chamnan розрахований на одну основну теку, до якої ви повертаєтеся знову і знову.** Усе, що він робить, оплачується наперед і повертається в наступних сесіях — у репозиторії, який ви відкрили один раз, ви заплатили повністю й не отримали нічого.

**Він повідомляє, а не переписує ваш код.** Індекс переносить коментарі, які ви вже написали, і нічого не вигадує. Файли без коментаря названо поіменно, щоб ви дописали їх самі.

**Його обмеження виміряні й записані**, разом із вимірюваннями, що свідчать проти його ж основної можливості.
