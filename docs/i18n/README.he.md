## מה זה

תוסף ל-Claude Code. הוא בונה אינדקס של המאגר שהסוכן קורא במקום לסרוק קובץ אחר קובץ, ושומר את ההקשר ההנדסי שנצבר תוך כדי העבודה — מצב העבודה, רישומי סשנים, הנימוקים שמאחורי החלטות, והנהלים שאתם גוזרים מחדש בכל פעם.

כל מה שהוא כותב הוא markdown פשוט שנשמר לצד הקוד. בלי קריאות רשת בזמן ריצה, בלי מסד נתונים, בלי תהליך רקע, בלי מודל embedding — רק ספריית התקן של Python.

## מה זה פותר

בכל סשן חדש, או בכל פעם שההקשר נדחס, כל מה שהסוכן הבין על הקוד שלכם נעלם והוא חוזר לחפש מההתחלה.

chamnan מונע את הגילוי החוזר הזה: האינדקס נמסר בתחילת הסשן, והמחיר הוא מספר ידוע וחסום ולא קריאות קבצים ללא גבול.

## התקנה

```bash
claude plugin marketplace add ArcticFox2029/chamnan
claude plugin install chamnan@chamnan
```

פתחו סשן חדש, והריצו `/chamnan:bootstrap` פעם אחת לכל מאגר.

## עם מה זה עובד

chamnan הוא טקסט ופייתון מספריית התקן. שום דבר באינדקס אינו שייך לספק מסוים, לעורך מסוים או למערכת הפעלה מסוימת.

| | |
|---|---|
| **כל מודל, כל ספק** | האינדקס הוא טקסט רגיל ונשלח כהקשר. המודל משנה רק כמה שווה לשלוח, לעולם לא לאן דבר הולך. את הגודל קובעים עם `--model`, `--window` או `--profile`. מעבר בין מודלים אינו מחייב התקנה מחדש. `--model` מזהה את המשפחות האלה לפי שם: `claude` · `codestral` · `deepseek` · `gemini` · `gemma` · `glm` · `gpt` · `grok` · `kimi` · `mistral` · `openai` — ההשוואה מתעלמת מאותיות גדולות וקטנות, ממפרידים וממספרי גרסה. `llama` ו-`qwen` הושמטו בכוונה: שתיהן יוצאות בכמה גדלים שדורשים תקציבים שונים, ולכן ציון שמן מחזיר את פרופיל ברירת המחדל ושורה שאומרת לאילו שני גדלים אפשר היה להתכוון. **מודל שאינו ברשימה עדיין עובד**: הוא מקבל את ברירת המחדל והערה שלא זוהה, ושום דבר לא נכשל. `--window` מקבל את המספר ישירות והוא תמיד מדויק. |
| **macOS, Linux, Windows, WSL** | אותו תוסף בכל מקום, ספריית תקן בלבד, אין מה להתקין. ב-macOS וב-Linux הפקודות רצות ישירות. ב-Windows המעטפת אינה יודעת להריץ סקריפט בלי סיומת, ולכן לצד כל פקודה וכל וו מונח קובץ `.cmd` שנוצר אוטומטית; הם נשלחים עם התוסף וה-CI מריץ דווקא אותם. WSL מתנהג כמו Linux. |
| **סוכנים רבים, אינדקס אחד** | Claude Code מקבל את הבלוק דרך וו של סשן, ולא נכתב שום קובץ בפרויקט שלך. גם ל-Gemini CLI יש וו סשן אמיתי. שאר הסוכנים מקבלים קובץ בנתיב שהם קוראים, ומי שקוראים אותו נתיב חולקים את הקובץ במקום שכל אחד יחזיק עותק שמתרחק מהאחרים. |
| **Hermes Agent** | Hermes הוא גם שכבת בקרה שמנצחת על סוכני קוד אחרים, ולכן מאגר שהוגדר עבורו פירושו לרוב כמה כלים שקוראים את אותו אינדקס. הוא מחפש הוראות פרויקט בסדר קבוע ולוקח את הראשון שהוא מוצא; chamnan כותב את הקובץ שבראש הסדר הזה, מתאים את הגודל למגבלה ש-Hermes עצמו מתעד, ומסרב לדרוס קובץ שלא הוא כתב. |

## קראו לפני ההתקנה

**chamnan מתאים לתיקייה מרכזית אחת שחוזרים אליה שוב ושוב.** כל מה שהוא עושה משולם מראש ונגבה בחזרה בסשנים הבאים — במאגר שפותחים פעם אחת שילמתם הכול ולא קיבלתם דבר.
